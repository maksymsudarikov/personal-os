# Quick Start — 3 steps

## Step 1: Prerequisites

You need Claude Code installed.
Download: https://claude.ai/code (free account works)

---

## Step 2: Clone and open

```bash
git clone https://github.com/maksymsudarikov/personal-os ~/personal-os
cd ~/personal-os
claude .
```

This opens the folder in Claude Code.

---

## Step 3: Run /setup

Type this in the Claude Code prompt:

```
/setup
```

Answer the 7 questions. Takes 10-15 minutes.

**One rule for Q2:** paste real text you've written (an email, a post, a DM) — don't type something fresh. This is the only rule that matters.

---

## After setup

- **Day 7:** run `/review` — get a score and see what gaps to close
- **Day 14:** run `/build` — find one automation worth shipping
